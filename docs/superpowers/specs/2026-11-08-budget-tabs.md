# Budget section tabs

Owner requested mutually exclusive tabs for Planned Commitments, Planned Expenses, Transaction-based Bills and Transactions. Default to Planned Commitments and retain existing transfer review as a fifth Transfers tab. Replace the previous jump shortcuts with the tab list; monthly overview remains a link.

The plan is loaded once. Its commitments and expenses share the same month/data and plan tabpanel, labeled by whichever of those two tabs is selected. Other panels are hidden via the native hidden attribute. Review forms remain mounted so unsaved edits and disclosures survive switching tabs. Confirm/exclude/save-for-review progression and save-error focus are deferred while their panel is hidden, then applied on returning to Commitments. The account history filter is only visible for transaction-based bills and transactions; it does not imply filtering manual plans.

Web adaptation: native buttons with tab/tablist/tabpanel semantics, selected state and roving tabindex. Left/right arrows wrap; Home/End select first/last; native Enter/Space activate buttons. Panels are keyboard focusable. At phone widths labels wrap and tabs form multiple rows rather than forcing horizontal page scrolling. Visible selected border/underline and weight supplement background color. Existing focus styles and at least 44px control dimensions are retained. Current HIG tab-bars reference was consulted; text retrieval returned the JavaScript shell.

Validation: synthetic browser checks verified all five tabs expose only one panel, Planned Expenses hides commitment forms, unsaved bill-name edits survive a complete tab round trip, and arrow/Home/End navigation selects and focuses the intended tab. At 390px width tab targets measured 172x70 or 350x46 CSS pixels. Phone screenshot reviewed and hover contrast corrected. Code review found no actionable regressions. Typecheck, production build and all 150 tests pass. Enlarged text, zoom and VoiceOver are not verified; no accessibility conformance claim. No bank requests or financial records were changed.
